Decisions applied in this revision

One asset per campaign. The campaign holds exactly one interest generator. The asset card replaces the Assets table; a follow-up is a second run of the same asset; a different piece means a new campaign. The ⋯ menu carries "Replace asset", locked after the first send. This supersedes PRD v2.3 §5.8–5.9 wording about several configurations per campaign.
Step 1 cards. Only MVI letter, Recent Activity postcard and Recent Activity flyer lead into steps 2–4 in this round; the other six select but disable Next with a note. General market analysis now shows as master-approved.
Who approves. Unchanged: both gates exclude the creator. Edson builds, Nolan approves.
Image library stays a picker inside Images (no sub-tab yet). Exceptions queue remains a proposal for open item 2.
